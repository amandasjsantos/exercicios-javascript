# Exercícios de JavaScript

Exercícios da disciplina **Linguagem de Programação para Web I**, com o objetivo de praticar JavaScript.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Estrutura

​```
exercicios-javascript/
├── 01-troca-de-cor/
├── 02-menu-em-cascata/
├── 03-relogio-tempo-real/
├── 04-formulario-confirmacao/
└── 05-carrossel-imagens/
    └── img/
​```

Cada exercício fica em uma pasta própria, com HTML, CSS e JavaScript em arquivos separados.

## Exercícios

### Questão 01

Criar uma página HTML na qual seja possível alterar a cor de fundo usando JavaScript.

### Questão 02

Criar uma página HTML com um menu em cascata usando JavaScript.

### Questão 03

Criar uma página HTML que chame a função de um relógio em tempo real usando JavaScript.

### Questão 04

Criar uma página HTML que simule um formulário, com um botão que chama um alerta "Tem certeza que quer salvar?", usando JavaScript.

### Questão 05

Criar uma página HTML com um carrossel de imagens usando JavaScript.
